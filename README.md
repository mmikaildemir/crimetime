# CrimeTime 2.0

New York State sentencing decision engine (`crimetime/`). See [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md)
for how the pipeline, sentencing tracks and data tables fit together.

## Web demo (GitHub Pages)

The demo in `site/` is a static page that runs the real Python engine in the browser via
[Pyodide](https://pyodide.org): `webapp/bridge.py` is the entry point, and offense data is
precomputed at build time. Nothing is sent to a server.

```sh
python scripts/build_site.py --serve   # build into _site/ and serve on http://localhost:8080
```

Pushing to `main` runs the tests, builds `_site/`, and deploys it via
`.github/workflows/pages.yml` (repo Settings → Pages → Source: **GitHub Actions**).

## Admin tool

`site/admin/` (served at `/admin/`) is where NYPTI admins keep the data current when the law
changes. They can edit offenses, statutory lists and sentencing ranges, see every sentencing
result their edit changes, and download a versioned data bundle. Deploying the bundle means
replacing the site's `data/` folder, with no rebuild. Hosting, publishing and rollback are
covered in [docs/HOSTING.md](docs/HOSTING.md). The checks live in `webapp/admin_bridge.py`.

## Legal review

`site/review/` (served at `/review/`) lets attorneys check the calculator one crime at a time.
For each crime, a plain-language sheet shows what the calculator says:
- classification and violent-felony status
- whether the crime can be sexually motivated, a hate crime or a crime of terrorism, including
  when only some subdivisions qualify
- what an attempt becomes
- the juvenile offender sentence
- the sentence with no, one or two prior felonies

The reviewer ticks **Wrong?** next to any incorrect line and says what it should be, then clicks
**Everything is correct — next crime** or **Save and go to next crime**. Answers stay in the
browser. When they're done, they click **Download my answers** and email the file back.

To build the report:
1. Put the answer files in `reviews/incoming/`. This folder is gitignored because the files
   contain reviewer names.
2. Run `uv run python scripts/import_reviews.py`.

It writes `reviews/report.md`, which lists every line marked wrong, grouped by crime and with
the reviewer's fix. If the calculator's output for a crime changes after it was checked, that
crime is listed as out of date.

The sheets are generated by `webapp/review_bridge.py` at build time. The statute text comes
from `data/statute_text.json`; refresh it with `uv run python scripts/refresh_statute_text.py`.
