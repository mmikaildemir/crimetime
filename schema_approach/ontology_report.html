Schema Description

Ontology for NY Penal Law offenses: classification + enhancement-reachability + attempt/conspiracy logic + source enumerated lists.

Core Axioms

A1_isCrimeA classification is considered a 'crime' if it is either a misdemeanor or a felony. Violations are not crimes under this definition.
Show formal axiom text
isCrime(x) <=> classification(x) in {Misdemeanor, Felony}
A2_isYOEligibleA crime is eligible for Youthful Offender treatment if it is a crime AND is not a Class A-I or Class A-II felony. CPL §720.10(2)(a) explicitly excludes Class A-I and A-II felonies from YO eligibility.
Show formal axiom text
isYOEligible(x) <=> isCrime(x) AND classification(x) not in {ClassA_I_Felony, ClassA_II_Felony} [CPL §720.10(2)(a) excludes Class A-I and A-II felonies]
A3_isVFOAn offense is a Violent Felony Offender (VFO) if it is a Class B, C, D, or E felony AND its section number appears in the VFO_LIST defined by PL 70.02(1). Attempt resolution requires special handling — see A11.
Show formal axiom text
isVFO(x) <=> classification(x) in {ClassB,ClassC,ClassD,ClassE}_Felony AND x.section in lists.VFO_LIST[matching class].sections [see A11 for attempt resolution]
A4_isSMFEligibleAn offense is eligible for Sexually Motivated Felony (SMF) treatment if it is a felony AND its section appears in the SMF_LIST defined by PL 130.91(2).
Show formal axiom text
isSMFEligible(x) <=> classification(x) == Felony AND x.section in lists.SMF_LIST.sections
A5_isHateCrimeEligibleAn offense is eligible for Hate Crime enhancement if its section appears in the HATECRIME_LIST defined by PL 485.05(3). This applies regardless of classification — misdemeanors and felonies alike can be hate crimes.
Show formal axiom text
isHateCrimeEligible(x) <=> x.section in lists.HATECRIME_LIST.sections [not felony-gated]
A6_hasPredicateExposureAn offense has 'predicate exposure' (meaning it can trigger enhancement for repeat offenders) if it is a felony AND is not a Class A-I felony. PL §70.06(1)(a) excludes Class A-I felonies from the second felony offender definition, but Class A-II felonies retain predicate exposure per §70.06(3)(a)/(4)(a).
Show formal axiom text
hasPredicateExposure(x) <=> classification(x) == Felony AND classification(x) != ClassA_I_Felony [PL §70.06(1)(a) excludes only Class A-I; §70.06(3)(a)/(4)(a) has live second-felony-offender table entries for Class A-II, so A-II retains predicate exposure]
A7_is70_04ReachableAn offense is reachable under PL §70.04 (PRI 2nd Degree, violent felony enhancement) if it is both a VFO AND has predicate exposure. This means the current offense itself must be a violent felony.
Show formal axiom text
is70_04Reachable(x) <=> isVFO(x) AND hasPredicateExposure(x)
A8_is70_06ReachableAn offense is reachable under PL §70.06 (second felony offender) if it has predicate exposure AND is not a VFO. This is the standard enhancement path for non-violent felony repeat offenders.
Show formal axiom text
is70_06Reachable(x) <=> hasPredicateExposure(x) AND NOT isVFO(x)
A9_classification_of_attemptWhen an offense is charged as an attempt, its classification is determined by an ordered branching rule per PL 110.05: (1) certain sections (murder 1st, CPCS 1st, etc.) stay Class A-I; (2) Class A-II stays A-II; (3) Class A-I downgrades to Class B; (4)-(6) specific bribery sections have overrides; (7) all others downgrade one class. Resolver function: resolveAttemptClassification(targetSection, targetSubdivision=None).
Show formal axiom text
classification(attempt_of_y) is resolved by an ordered branching rule against target y, per PL 110.05: (1) if y.section in STAYS_A_I_LIST -> ClassA_I_Felony [no downgrade]; (2) else if y.classification == ClassA_II_Felony -> ClassA_II_Felony [no downgrade]; (3) else if y.classification == ClassA_I_Felony -> ClassB_Felony; (4) else if y.section == '200.00' -> ClassD_Felony [bribery 3rd override]; (5) else if y.section == '200.03' -> ClassC_Felony [bribery 2nd override]; (6) else if y.section == '200.04' AND subdivision == '2' -> ClassB_Felony [bribery 1st subd.2 override -- see A14 subdivisionSensitiveAsAttemptTarget]; (7) else -> standard one-class downgrade per STANDARD_DOWNGRADE_TABLE. Note: 125.26 (aggravated murder) is deliberately excluded from STAYS_A_I_LIST because the A-I-stays-A-I treatment applies only to subdivision 1, not the whole section -- see A14 subdivisionSensitiveAsAttemptTarget, do not add '125.26' as a flat entry here.
A10a_isAttemptAn offense is charged as an attempt when the defendant intended to commit a completed offense and took a substantial step toward it. The attemptOf field points to the completed offense section.
Show formal axiom text
isAttempt(x) <=> x charged as attempt of completed offense y; attemptOf(x) = y
A10b_isConspiracyAn offense is charged as a conspiracy when the defendant agreed with one or more persons to commit a crime. The conspiracyOf field points to the target offense. Article 105 conspiracy degree sections are generic — conspiracyOf is only set when the charge is tied to a specific named completed offense.
Show formal axiom text
isConspiracy(x) <=> x charged as conspiracy to commit completed offense y; conspiracyOf(x) = y [Article 105 conspiracy degree sections are generically worded by target-crime severity, same pattern as Article 100 solicitation -- conspiracyOf is only set when the charge is tied to a SPECIFIC named completed offense, not for the generic degree definitions themselves]
A11_VFO_of_attemptVFO status for attempts is determined by checking the VFO_LIST: (a) if the target offense is explicitly listed in a VFO class's attemptOfSection array; (b) if the target's VFO class has an attemptOfClass rule; or (c) if the target is in the lesser-included carve-out. This requires a resolver function, not a simple lookup.
Show formal axiom text
isVFO(attempt_of_y) <=> resolve against lists.VFO_LIST using one of: (a) y.section appears in some class's attemptOfSection array (named carve-out, e.g. attempt of 125.25/135.25/150.20 -> classB), or (b) y.classification's VFO class C has attemptOfClass containing y's actual VFO class (e.g. attempt of a classB VFO -> classC VFO via generic downgrade rule), or (c) y.section appears in classE's attemptOfSection_lesserIncluded (weapon-possession lesser-included carve-out). This requires a resolver function, not a flat membership check -- see lists.VFO_LIST structure.
A12_SMF_of_derivativeAn attempt or conspiracy is SMF-eligible if the target offense is SMF-eligible AND the SMF_LIST includes attempts and conspiracies (which it does per PL 130.91(2)'s blanket catch-all).
Show formal axiom text
isSMFEligible(z) <=> (isAttempt(z) OR isConspiracy(z)) AND isSMFEligible(attemptOf(z) or conspiracyOf(z)) AND lists.SMF_LIST.includesAttemptsAndConspiracy
A13_HateCrime_of_derivativeAn attempt or conspiracy is hate crime-eligible if the target offense is hate crime-eligible AND the HATECRIME_LIST includes attempts and conspiracies (which it does per PL 485.05(3)'s blanket catch-all).
Show formal axiom text
isHateCrimeEligible(z) <=> (isAttempt(z) OR isConspiracy(z)) AND isHateCrimeEligible(attemptOf(z) or conspiracyOf(z)) AND lists.HATECRIME_LIST.includesAttemptsAndConspiracy
A14_subdivision_sensitiveTwo independent axes: (a) OWN DERIVATION — some offenses have subdivisions where modifiers apply only to specific subdivisions (e.g., 125.15 subd 1 is SMF/HC-eligible, subd 3 is not). (b) ATTEMPT TARGET — some offenses are treated differently as attempt targets (e.g., 125.26 subd 1 stays Class A-I on attempt, subd 2 does not). These axes are independent; an offense may be true on one, both, or neither.
Show formal axiom text
Two independent axes: (a) OWN DERIVATION -- subdivisionSensitiveOwnDerivation=true means this offense's own memberOf/derived vary by subdivision when charged as a completed offense (e.g. 125.15: subd 1 SMF/HC-eligible, subd 3 not). Resolver selects subdivisions[n].memberOf/derived instead of the offense-level summary. (b) ATTEMPT TARGET -- subdivisionSensitiveAsAttemptTarget=true means A9's branch (6) or A1_STAYS_A_I_LIST logic treats subdivisions of this offense differently when it is cited as an attemptOf target (e.g. 125.26: only subd 1 stays ClassA_I per 110.05(1); 200.04: only subd 2 stays ClassB per 110.05(9)). Resolver selects subdivisions[n].attemptOverride.classification instead of applying A9's default branches to the offense's flat classification. These axes are independent; an offense may be true on one, both, or neither. Offense-level fields remain the fallback wherever the relevant flag is false.
A15_STAYS_A_I_LISTSections whose attempt classification stays Class A-I per PL 110.05(1): 125.27 (aggravated murder), 220.21 (CPCS 1st), 220.43 (terrorism 1st), 490.45 (terrorism 2nd), 490.55 (terrorism 3rd).
Show formal axiom text
Sections whose attempt classification stays ClassA_I_Felony per PL 110.05(1): ['125.27', '220.21', '220.43', '490.45', '490.55']. These are evaluated at A9 branch (1) before any downgrade.
A16_STANDARD_DOWNGRADE_TABLEDefault one-class downgrade per PL 110.05 when no override applies: Class B felony → Class C, Class C → Class D, Class D → Class E, Class E → Class A misdemeanor, Class A misdemeanor → Class B misdemeanor. Class B misdemeanor has no entry — unverified what attempt of Class B misdemeanor resolves to.
Show formal axiom text
Default one-class downgrade per PL 110.05 when no override applies (A9 branch 7): ClassB_Felony → ClassC_Felony, ClassC_Felony → ClassD_Felony, ClassD_Felony → ClassE_Felony, ClassE_Felony → ClassA_Misdemeanor, ClassA_Misdemeanor → ClassB_Misdemeanor. ClassB_Misdemeanor has no entry — unverified what attempt of Class B misdemeanor resolves to. Flag as open until confirmed.
A17_hate_crime_bumpIf an offense is hate crime-eligible AND the hate_crime_motivated answer is true, look up the base classification in the HATECRIME_BUMP_TABLE: misdemeanor or Class C/D/E gets bumped one category higher; Class B gets fixed minimum floors per predicate status; Class A-I gets flat minimum 20 years. Offense-level sentencing stays empty — bump is resolved from the shared table.
Show formal axiom text
If isHateCrimeEligible(x) AND hate_crime_motivated answer == true → look up x.classification in sentencing_tables.hateCrimeBump → apply matching branch. Bump logic (how sentence changes) lives in ny_sentencing_tables.json, not here. Eligibility (whether the offense can be a hate crime) is owned by HATECRIME_LIST and the isHateCrimeEligible derived flag.
